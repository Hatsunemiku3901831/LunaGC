# 任务测试夹具的资源快照

交叉回归的运行线程多次停留在 `QuestTestFixture.setup` 的全量 JSON 解析。
该夹具每次读取约 48 MB 的任务表，之后只使用父任务 `11005`、`11103`、`19090`、`309` 的 48 项子任务。

`QuestFixtureResources` 按文件实际路径、修改时间、大小和父任务集合保存未初始化的 JSON 快照。
每次调用都重新解析快照，返回独立任务对象及嵌套集合；`onLoad` 仍由原夹具逐次执行，
没有缓存可变的已初始化任务，也没有修改生产资源加载器或减少原有任务范围。

`QuestFixtureResourcesTest` 的三项检查均通过：

- 修改一份任务及其嵌套列表，不影响下一份对象；不同父任务集合不会混用。
- 资源文件修改后重新生成快照。
- 当前资源中全部 48 项任务与原全表读取结果的已映射字段完全一致。

一次本机采样：原全文为 48,266,197 字符，筛选后的快照为 32,697 字符；
全文解析筛选约 255.5 毫秒，缓存后的独立对象解析约 3.9 毫秒。
这是测试夹具的一次采样，未作为生产性能或固定耗时保证。
