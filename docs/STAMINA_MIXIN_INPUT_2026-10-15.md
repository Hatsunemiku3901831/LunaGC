# 体力回调的零消耗与无效输入

复核已有 CostStaminaMixin 时发现，配置或天赋计算得到零值会被强行改成 1。
错误表达式的零回退也会触发同一问题，并修改共用时间戳。

本次保留明确的零值，零消耗不修改体力、时间戳或发送体力通知。
无效表达式、NaN、无穷数、已失效的能力承载实体或目标、禁用的配置拒绝执行。
当前资源包含负的体力增减配置，已有正负值行为保留。

本次只修正输入检查；原有共用计时、500 毫秒间隔及整数换算继续单独核对，
没有声称完整替代客户端逐帧体力结算或实现 onStaminaEmpty 动画控制。
