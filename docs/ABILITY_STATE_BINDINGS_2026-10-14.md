## 实现

- 原样保留 abilityStates、reject 及待确认的额外控制字段，非法形状不阻断整个资源文件解析。
- 从承载实体的当前登记实例读取状态，包含尚未分配客户端 ID 的服务端控制器。
- 根能力、Default 及已登记父修饰器参与监听；移除能力、父修饰器或状态会重新计算需求。
- 状态与全局值监听共用子修饰器需求与所有权记录，避免分别建立两份相同子效果。
- 状态绑定创建子控制器前校验完整进入／移除动作树，复用现有回调、条件、动作额度和生命周期。
- 同名独立实例、预先存在的控制器及外部具名替换保持独立；状态绑定只释放自己创建的控制器。
- 客户端确认沿用服务端控制器，不重复进入回调；移除登记和清理回调在登记锁外完成。
- 当前没有动作实现、未知条件或待确认控制字段的配置保留原内容，继续作为待接入范围。
