# 家具启动资格、材料确认与独立任务编号

参考 AstaPS 的制作流程，确认双方原流程均未校验图纸所有权、任务编号默认全部为 0，材料扣除和启动保存缺少结果确认。
本批补齐这些业务缺口，开始响应沿用前批原生阶段 1 候选，未把候选当作已完成实机配对。

## 启动规则

- 玩家必须拥有当前家园、学习对应家具图纸；制作和成品定义必须真实、数量与时长有效。
- 非零角色 ID 必须是玩家已拥有的角色，当前未增加制作天赋效果。
- 必须有明确且正数的制作容量；缺失容量返回配置错误。真实满队列才返回槽位已满。
- 空的旧队列可以初始化；空条目、负编号和重复编号拒绝启动。新任务使用当前队列中未占用的最小非负编号。
- 先合并重复材料、检查正数与溢出、材料类型、归属和足量，再预约启动。
- 保存材料 ID、稳定数据库 ID、扣除前数量和费用，确认每种材料实际减少数量并同步保存；确认支付后才创建任务和保存队列。
- 保存失败保留启动记录，禁止新启动和领取，避免再次扣费或领取尚未确认的任务。没有自动退款或自动重放。
