# D02-M0-DATA：独立实例出生资源准备

## 实际范围与状态

本项实现可重复的具名离线准备入口 [prepare_d02_m0_resources.py](../tools/migration72/prepare_d02_m0_resources.py)，仅面向 `questing.enabled=true` 的女主 `10000007`，基础及当前 depot 均为 `701`；不生成 `704`。输入固定 hash，缺失、不匹配或具名行不唯一时失败。输出仅写 `<InstanceRoot>/resources` 下脚本明确列出的文件，不清空目录，不写实例 config、data、数据库、JAR 或 resources 子模块。重复运行会重写这些具名输出；不要把其他用途的同名文件放入此实例。

这是一套有限准备输入，并非 Java 全加载、M0入场或完整 D-02 ready 证明。真实 `ResourceLoader → Player/装备/recalc → 独立库保存/重读` 和缺依赖拒绝由唯一集成者串行验收；本项离线结果不代替这些验证。A/B、preview及准确依赖冻结保持。
