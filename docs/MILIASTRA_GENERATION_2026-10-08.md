# 千星实体与像素画生成

本文记录实体与像素画生成。第二十七批新增的镜头模板、参数和批量变体见
[镜头生成](MILIASTRA_CAMERA_2026-10-08.md)。

## GM 操作

在「千星资产」中展开「生成实体 / 像素画 / 镜头 .gia」，选择图片或实体 JSON，设置输出文件名，点击「生成并归档」。
生成结果进入现有资产目录，可检索、分页和「导出原文件」。无需玩家 UID，沿用 GM 身份校验。

图片支持 JDK ImageIO 可读取的 PNG／JPEG／BMP／GIF，GIF 使用第一帧；输入最多 16 MiB、1600 万像素。
输出默认 240×240、保持比例、像素边长 0.1、透明度阈值 128、XY 平面、原点 (0,0,0)。
宽高各 1–1000，乘积最多 100000。保持比例时按边界缩小，最窄方向至少 1 像素。
采用 Java bicubic 缩放；这是与上游 Pillow Lanczos 的实现差异，不声称图片结果逐像素相同。

透明度低于阈值的像素跳过，阈值 0 会保留全透明像素。原图底部作为纵坐标 0。
色彩使用 HSV 圆柱距离匹配 21 种参考方块；缩放按模板实际尺寸及各轴默认缩放归一化。
XY、XZ、YZ 各自在对应两轴铺开，并保留第三轴及输入原点。

实体 JSON 示例：

```json
{
  "blocks": [
    {
      "templateId": 20001224,
      "name": "木箱",
      "position": {"x": 0, "y": 0, "z": 0},
      "rotation": {"x": 0, "y": 90, "z": 0},
      "scale": {"x": 1, "y": 1, "z": 1},
      "static": true
    }
  ]
}
```

根对象只接受 `blocks`，模板 ID 为正 int32；可选正 int32 的 `guid`、字符串 `name`、三轴向量和 `static`。
位置、旋转默认 0，缩放默认 1，静态默认 true；所有向量使用有限 float32，缩放须大于 0。
拒绝未知字段、重复 JSON 属性、重复 GUID、错误类型及越界值，避免悄悄丢弃输入内容。
JSON 最多 8 MiB、200 万个值、64 层嵌套，1–100000 个实体；名称最多 4096 字符。
任意正模板 ID 可用于实体模型，是否存在于当前客户端仍需编辑器验证。

## 文件与 ID

独立 GIA 写入器依据固定版本的 proto 写入实体元信息、模板引用、名称属性、位置／旋转／缩放组件与 `field_501`。
输出继承归档的 32 MiB 单文件、2000 个文件、512 MiB 原文件存储上限。
资产扫描上限由 4096 改为 100000；只持久化前 100 项预览，列表显示完整计数。
重合检查扫描原文件中的全部主资产 GUID，包含预览之外的条目。

默认自动起点至少为 1078000000，并位于已有归档和本次明确指定的最大正 int32 GUID 之后。
指定起点时检查整个连续区间；显式 GUID、自动区间、归档之间重合均拒绝，溢出也拒绝。
同一服务实例串行分配，服务重启后重新扫描归档；破损的归档会阻止继续分配。
已有文件可保留同 GUID 的不同版本，导入会提示冲突；生成器不会自动改写已有文件。
自动分配范围只包含本服务归档的主资产，未归档的编辑器文件和关联依赖不在保证范围内。
独立服务实例同时写同一目录也不在跨进程分配保证范围内。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/gm/api/miliastra/palette` | 模板列表及 ImageIO 支持的格式 |
| POST | `/gm/api/miliastra/generate/model?name=实体.gia&firstGuid=...` | 原始实体 JSON 请求体 |
| POST | `/gm/api/miliastra/generate/image?name=像素画.gia` | 原始图片字节 |

`firstGuid` 不传即自动分配。图片参数为 `width`、`height`、`keepAspect`、`unit`、`alphaThreshold`、`plane`、`x/y/z`。
生成成功返回 201，响应含归档 `asset`、实体总数 `count`、自动分配数量 `automaticCount` 与 `firstAutomaticGuid`。
输入错误 400、无权限 403、请求体超限 413；大文件读取受限请求流，不提高其他 GM 接口的限制。
