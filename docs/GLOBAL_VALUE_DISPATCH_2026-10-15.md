# 按全局值分发动作

接入当前资源的 `DoActionByGlobalValue`，补齐全局值读取、区间选择、默认动作、
嵌套动作编号、周期执行和原生确认去重。该父动作也是 TPS 弹药包的补给入口之一。

## 当前客户端证据

二进制、metadata 与 startup 继续按[提取工具](../tools/extract_client_type_names.py)的 SHA-256 固定。
动作配置类型 `NOMANJFJBPN`（12833）的执行入口 `0x153d56e10`
委托给 `IMHPJAGBBNN.MHMEGAEEFJE`（`0x14a7e5c20`）。

| 资源字段 | 本地字段 | 配置偏移 |
| --- | --- | --- |
| `valueSteps`／`ACDIBKKMCCK` | `valueSteps`，动态区间端点 | `0x60` |
| `IAMAGJDLMAI` | `defaultActions`，默认动作数组 | `0x68` |
| `FKPKBNOINEG` | `globalValueProvider`，键名提供器 | `0x70` |
| `NGHBADANOHL` | `actionSteps`，分组动作数组 | `0x78` |

原生在 `0x14a7e5d71` 至 `0x14a7e5d79` 使用相邻端点的左闭右开区间。
按原始顺序取第一个匹配区间；没有把不单调端点重新排序。
全局键缺失、少于两个端点、无匹配区间或匹配索引超出分组数量时，使用默认动作。
选中的空数组保持空操作，不跳到默认分支。

全局读取助手 `0x14a7e5f90` 查找能力所属实体的控制器 `0xc0` 字典。
动作目标影响接收者，不把键值读取改成接收者的字典。
控制器的父对象 `EFAGOAGAKFF` 通过 `0x28` 持有来源实体，动态键名也沿该实体查找控制器。

当前资源的键名提供器只有两种，均已接入：

- `AFKDGJBEGHN`：`GLPOFOEFFNL` 位于 `0x152729430`，返回静态键名；
  兼容 `name` 与原字段 `JJGDPDEHLKJ`。
- `OOMODMGBDEP`：`GLPOFOEFFNL` 位于 `0x14b8c3c50`，读取来源全局计数，
  先截断为 int，再追加到 `JLECIDOAMFG` 前缀后。计数键为 `HNEGOANIAHN`，缺项取 0。

配置对象访问器 `0x153d57080` 按分组 `0x78`、默认数组 `0x68` 的顺序访问。
本地编号生成据此先遍历全部分组，再遍历默认数组，继续编号后续根动作。
固定编号向量和独立分组对象已在测试中核对；当前客户端实际回包编号仍待实机验收。

## 服务端执行与确认

- 注册真实动作处理器，按动态端点求值，沿用有序动作、目标解析、生命周期和工作量限制。
- 周期树每次按当前来源值重新选择；只在整棵树的动作与条件都受支持时接管周期执行。
  未选择的分支同样纳入确认归属，不能由客户端绕过周期。
- modifier 添加阶段的标量选择按该次状态应用记账；重复添加或父动作确认不会重新选择另一分支。
- 对 modifier 添加／移除树中的分发子动作，原生叶子确认交由服务端父动作处理，
  避免直接确认未选择的武器补给分支。该缓存不写入资源 JSON 或玩家存档。
- 服务端已接管的周期／触发补给确认不重复运行；已移除实例的迟到父确认被拒绝。
  真正移除后重新添加的新实例可以作出新选择。
- 移除阶段只做冷却记账的上下文可以遍历该结构，但不会因此重放弹药发奖。
- 非法提供器、键、非有限值、越界计数或无效端点表达式拒绝执行，不误当作默认分支。
  未配对的键名提供器和目标形态没有被当作通用支持。
