## 行为

- 图纸／食谱须指向实际存在且 ID 匹配的非默认配方，玩家尚未学会；一次学习使用一件。
- 已学会、默认可用、未知、错位、空参数或非法 ID 均不消耗学习物品。
- 直接调用三类解锁方法也检查相同资格，避免把未知配方 ID 写入玩家解锁记录。
- 库存使用入口拒绝非正数量、外来所有权和超出资源单次使用上限的请求。
- 删除物品返回失败，或数量未实际减少指定数量时停止，三类学习后置动作不会执行。
- 正常学习消耗一件并发送一次通知。实际资源图纸 221001 经完整库存入口解锁配方 22001。

当前资源含 23 种炼金图纸、44 种锻造图纸与 284 种食谱学习物品，共 351 种。
它们的单次使用上限均为 1，且只有一个有效学习动作；资源统计与行为回归分别核对。
