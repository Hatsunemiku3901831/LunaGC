# 锻造产物与退款回包

本批沿当前客户端解析、字段布局和接收流程核对 `ForgeQueueManipulateRsp`。
移除产物和退款的占位标签，把服务器传入的物品写入产物、退款和额外产物列表。

| 字段 | 标签 | 原生对象偏移 |
| --- | --- | --- |
| 产物列表 | 2 | `0x28` |
| 额外产物列表 | 3 | `0x18` |
| 错误码 | 6 | `0x30` |
| 操作类型 | 9 | `0x34` |
| 退款列表 | 11 | `0x20` |

原生类型 20172 `BCGFIDDBMBD` 的解析函数为 `0x147f4f500`。
接收方法 `0x14b14d400` 先处理 `0x28` 的主要物品列表，再处理 `0x20`、`0x18` 的附加列表。
后两者的提示项设置额外物品标志；沿用已有额外产物标签 3，因此主产物和退款对应标签 2、11。
这些列表转换为包含 ID、数量和 GUID 的物品获得提示。

嵌套 `ItemHint` 类型 46593 的解析函数 `0x14fba8410` 确认
物品 ID 1、数量 2、新物品标记 3、GUID 4、附加列表 5，保留项目现有共享定义。
同名语义字段在不同消息的内存位置不同，未依据字段顺序猜测标签。

请求写入 `0x14f4c1110` 保持队列 ID 15、操作类型 2。
原生包号返回方法确认请求 2573、回包 22232。
操作枚举数值沿用现有定义，本批未独立解码枚举常量。
