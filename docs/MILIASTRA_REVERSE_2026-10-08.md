# 节点 GIA 反向生成编辑器画布

GM「千星资产」中的普通节点 GIA 与 `.gia.json` 卡片提供「转为编辑器画布 JSON」。
转换结果单独归档为 `GRAPH_JSON`，原文件继续保留；操作无需玩家 UID。

## 使用

1. 导入节点 GIA 或节点结构 JSON，点击「转为编辑器画布 JSON」。
2. 点击新卡片的「导出原文件」下载 `.canvas.json`。
3. 修改节点位置、输入常量、明确的类型、分支标签、连接或注释后重新导入。
4. 点击「转为 GIA」并下载结果。已有节点沿用原索引，新节点分配未使用的索引。
5. 需要一个新 GUID 的独立副本时，使用 [复制并重新编号](MILIASTRA_GUID_2026-10-08.md)。

画布根字段 `giaSource` 保存 `lunagc.canvas-source.v1` 格式标记与完整原始 GIA 的 Base64。
未编辑的画布恢复完整原字节并复用原 SHA-256 归档。修改后的文件沿用原 GUID，生成新的内容归档；
不能将同 GUID 的两个版本当作独立资产同时导入游戏。
外部编辑器若移除 `giaSource`，将回到普通正向生成流程，无法再保留原生画布之外的字段。

## 映射与保留

支持版本 1 的普通节点图：服务端基本／状态／职业／道具图，以及客户端技能、布尔与整数过滤器
（类型 9、22、23、46、11、10、47）。客户端技能子环境没有独立字段时，选择所有节点共同支持的环境；
多个环境可用时选择目录中的首个环境，不将它视为客户端原始编辑器模式的证明。

| 内容 | 处理 |
|---|---|
| 节点 | 使用模板、具体类型、原生引脚类型和常量核对目录；只接受唯一完整映射 |
| 常量 | 标量、零值、布尔、向量、枚举、列表、字典与具体类型包装还原为可编辑值 |
| 连接 | 核对方向、节点及双重索引；去除输入／输出两端重复表示的同一条连接 |
| 分支 | 保留字符串或整数标签，恢复动态流程输出与隐藏标签输入 |
| 注释 | 节点附注与自由注释均保留；额外附注按正向编译规则转为带位置的图注释 |
| 原始数据 | 保留图 GUID、已有节点索引、原图名称、变量、关联、附件、路径及未映射的已知字段 |
| 未知字段 | 修改后的相关 protobuf 消息保留 `$unknown`；列表元素按原序号合并，不作为隐藏引用推断 |
| 节点类型变更 | 重新生成引脚；含未知字段或额外原生参数时拒绝更换类型，改用结构 JSON 编辑 |

无名称的原图使用「未命名节点图」作为画布显示名；只修改节点不会向原图补写名称。
同一引脚内的重复连接、重复节点索引、失效引用、索引不一致与方向错误给出诊断。
复合图、结构定义、自定义节点、未支持常量和多个匹配模板不能生成部分画布，原文件仍可导出。
删除仍被复合引脚引用的节点也会拒绝；来源画布不能直接改变图环境或指定其他 GUID。

输入继续受 32 MiB 原文件、8 MiB 画布、10000 个节点、40000 条连接及现有 JSON／归档配额限制。
原文件 Base64 同样计入画布大小，因此不是所有 32 MiB GIA 都能生成 8 MiB 内的画布。
未编辑时保证原字节；编辑后的 protobuf 重新编码只保证已保留字段的语义，非规范编码及字段顺序可能变化。

## 接口与来源

`POST /gm/api/miliastra/{SHA-256}/canvas` 沿用 GM token 与来源限制。
新画布返回 201，已有画布返回 200；不支持内容返回 400，缺少权限 403，不存在 404，归档损坏 500。
还原沿用 `POST /gm/api/miliastra/{SHA-256}/convert`，返回新的 GIA 或原归档。

节点定义来自固定 [WebMiliastraNodesEditor](https://github.com/Columbina-Dev/WebMiliastraNodesEditor/tree/f2a5e2055d99b82cb4a6b2197e00f3106f4223d7)
及 [MIT 配套协议工具](https://github.com/Wu-Yijun/Genshin-Impact-Miliastra-Wonderland-Code-Node-Editor-Pack/tree/5d85fc474428686c6705be03ebd8b3139f1952f3)。
结合用户提供的 [UGC-File-Generate-Utils](https://github.com/luern0313/UGC-File-Generate-Utils) 的原文件封装与资产协议工作，
本项目独立实现转换，不执行参考库脚本。完整许可、提交及摘要随 `miliastra` 资源保留。
参考节点协议标记 6.2.0，当前 7.1 客户端实机导入、执行与奖励尚未验证。

## 验证

旧接口 404 先复现；真实 381 字节样本覆盖三个节点、三条连接与原字节还原。
测试检查常量编辑、泛型、客户端类型码、稀疏索引、新增与重排节点、镜像连接、注释、
未知字段、变量、类型更换保护、重启与重复转换。

默认单节点目录检查覆盖 702 个环境案例：665 个通过未编辑原字节还原和坐标编辑后的原生字段对比；
4 个反向案例存在多个匹配模板（射线结果两种过滤器、攻击盒位置／挂接点），33 个沿用正向诊断。
这些检查不覆盖所有配置拓扑，也不代表游戏运行通过。
完整测试、浏览器交互、原始 proto 独立解码与构建结果见 [上游整合记录](UPSTREAM_INTEGRATION_2026-10-08.md)。
