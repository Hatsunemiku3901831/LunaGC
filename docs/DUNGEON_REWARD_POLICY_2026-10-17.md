# 秘境可选奖励策略：2026-10-17

参考 AstaPS 固定提交 `7cc148d1f752a43d4b9146b3b73f26875902546f` 的
`MaterialDomainTripleHelper` 和 `ReliquaryDomainBonusHelper`。
默认沿用资源及当前掉落配置；管理员可独立启用材料倍率和圣遗物秘境强化材料追加。

## 配置

在 `config.json` 的 `server.game.gameOptions` 中配置：

```json
{
  "dungeonRewards": {
    "talentMaterialMultiplier": 1,
    "weaponMaterialMultiplier": 1,
    "relicEnhancementBonus": false
  }
}
```

旧配置缺少此项或将其设为 `null` 时，奖励数量保持原值。修改后执行无参数 `reload` 或重启。
`reload dungeon-drops` 只重载掉落文件，不重载本节服务器配置。

要启用参考增强，可将两个倍率设为 `3`，将 `relicEnhancementBonus` 设为 `true`。
三个设置独立生效，无需修改资源文件或 `DungeonDrop.json`。

## 材料倍率

天赋／武器材料秘境按各自配置，对原始抽取结果中的 `ITEM_MATERIAL` 数量乘以正整数倍率。
沿用参考的货币排除表 `101/102/104/105/201/202/203/204`；不放大阅历、摩拉等虚拟奖励或装备数量。
圣遗物、周本及其他类型不使用这两个倍率。

倍率在本次普通／浓缩树脂的完整抽取之后执行，适用于自身加权根表、独立掉落配置及缺表原型。
例如浓缩抽得两份材料合计 4 个，再启用三倍，最终为 12 个；费用与原领取次数规则保持一致。
对应秘境的倍率为零、负数或乘法溢出时，本次领取拒绝，不扣费用，修正配置后可以重试。

## 圣遗物秘境强化材料

仅在本次有有效基础奖励，且没有抽到 `105003` 或 `105002` 时，追加：

- `105003` 祝圣精华：均匀抽取 6–12 个，含端点。
- `105002` 祝圣油膏：均匀抽取 7–10 个，含端点。

沿用参考的每次领取追加一次规则，浓缩树脂不再次倍增这份追加奖励。
若原始奖励已有任意一种，则两种都不追加；保留已抽得的原始数量。
参考实现会删除 `105005` 祝圣之霜；本项目保留该物品和掉落配置中的其他原始奖励，
不会为启用追加策略而删除原始物品。物品名称及内容仍以当前资源定义为准。

## 结算保护

完整抽取与策略计算成功后，整批奖励一起检查真实背包容量、堆叠上限和费用。
追加物品定义缺失、追加后背包不足、倍增后超过上限、空抽取或零数量抽取都不能扣费。
不会通过静默截断数量让容量检查通过，也不会用追加材料把空掉落变成可领取奖励。
同一秘境实例的领取占用和已领取保护仍覆盖完整策略。
