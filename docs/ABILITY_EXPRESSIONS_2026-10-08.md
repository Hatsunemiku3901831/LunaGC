## 已修复

- 加、减、乘、除在运算前验证操作数数量；空表达式、多余操作数、缺少指令类型和空变量名均返回调用方指定的默认值。
- 除数为正零或负零、数值溢出、常量或属性含 `NaN`／无穷大时，不向技能动作传播无效数值。
  调用方默认值自身无效时返回零。
- 保留后缀表达式的左右操作数顺序，以及 `%1`、`-%1` 和布尔值的既有含义。
  未定义的普通变量仍按零参与运算。
- 指令名称解析使用固定区域规则，避免系统语言影响小写 `div` 的识别。
- 遇到尚不支持的对象形式时，完整读过该 JSON 值，保留调用方默认值；后续字段继续正常读取。

例如，`["Power", 2, "DIV"]` 在 `Power = 12` 时得到 6。
`["Power", 0, "DIV"]` 返回该调用方的默认值。
治疗动作的异常表达式会得到零治疗量，后续合法治疗仍可正常执行。

## 真实资源与天赋运算的边界

只读扫描当前能力资源，找到 **7,745 个含加、减、乘、除指令的标量后缀表达式**；这些表达式的操作数结构均完整。
缺少操作数的失败通过独立夹具复现，没有把当前资源误报为已损坏。
回归测试逐一读取这 7,745 个表达式，用独立计算器核对结果；变量采用受控值，
因此这项验证证明表达式兼容性，不能代替角色技能倍率和实际战斗验收。

天赋配置另有 `ModifyAbility` 的增量、比例和控制标志。
当前资源中有 5,828 条明文 `ModifyAbility`，其中 2,351 条含 `paramRatio`；这部分计算仍未完成。
公开参考实现只声明或部分读取这些字段，尚不足以证明完整公式。

本批使用 r2mcp-basic 流程只读核对提供的客户端；MCP 会话连接关闭后，使用本机 radare2 CLI 保留最小范围反汇编证据。

没有据此增加字段别名或写入猜测公式。客户端文件未修改。
