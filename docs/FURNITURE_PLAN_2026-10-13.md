# 家具任务保存启动时的产物与材料信息

延续已确认的制作支付与领取流程，为新任务保存定义快照。
此前任务只保留制作 ID 和时间，领取重新读取可更新的资源，导致已支付任务的产物、数量和信任经验可能随资源变动。

## 保存和领取

- 新任务保存快照格式版本、制作 ID、家具物品 ID、数量、原始时长、首次信任经验，以及合并后的实际材料费用。
- 快照随制作任务同步保存，支付未确认时仍不能进入可领取队列。
- 新任务领取使用保存的产物和经验；对应配方后来改变或被移除，仍能按启动记录领取。
- 物品定义、背包容量和所有权仍在领取时检查。缺失成品定义、损坏快照或未知版本会保留任务并拒绝领取，不回退到新配方。
- 正常与仙速瓶加速领取共用保存的产物计划；首次制作判定仍按家具物品 ID 执行。
- 原生任务回包字段保持不变，内部快照没有增加协议字段。

旧任务没有原始定义，继续使用有效的现有配方；无法据此保证旧任务更新前的真实费用与产物。
本批没有猜测旧记录，也没有实现取消退款、自动恢复或制作天赋。
