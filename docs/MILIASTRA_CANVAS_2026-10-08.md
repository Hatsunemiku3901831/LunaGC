# 千星编辑器画布 JSON 转 GIA

## 操作流程

GM「千星资产」导入 WebMiliastraNodesEditor 的画布 `.json` 后，点击「转为 GIA」。
转换结果进入原有资产归档，点击「导出原文件」下载；无需玩家 UID。
相同画布重复转换或重启后再次转换，会复用相同 GUID 与文件，不增加重复归档。
转换失败时显示具体节点、端口或类型原因，已导入的画布原文件仍可下载。

画布支持 schemaVersion 1／2，服务端、客户端技能、布尔过滤器和整数过滤器环境。
输入上限为 8 MiB、10000 个节点、40000 条连接；原有 JSON 深度、值数量和归档配额限制继续适用。
实际节点必须有当前参考目录内的唯一模板与环境定义，不能据此认定每种环境的全部节点已支持。
普通节点 GIA 及 [节点结构 `.gia.json`](MILIASTRA_NODES_2026-10-08.md) 可反向输出带原文件来源的编辑器画布，
支持范围、保留规则与验证见 [反向画布转换](MILIASTRA_REVERSE_2026-10-08.md)。

## 常量、类型与端口

节点字符串 ID 按文档顺序转换为从 1 开始的节点编号；位置按 float32 检查。
流程输出连接目标流程输入，数据输入记录来源数据输出；拒绝方向错误、多个来源连接同一数据输入及失效引用。
`data.overrides` 设置数据输入常量；未连接输入使用目录默认值。已连接输入的显式常量作为该输入的回退值保留。
整数及 ID 必须为 int32，布尔值、字符串、有限 float32 和向量均检查实际类型，不通过截断或字符串强制转换接受错误值。

泛型根据参考模板、显式类型、常量及整张图的数据连接求解；使用中的泛型仍有歧义时，需要 `data.giaTypes`。
类型使用参考表达式，例如 `Int`、`Flt`、`Bol`、`Str`、`Vec`、`L<Int>`、`D<Str,Int>`、`E<编号>`。
`giaTypes` 只指定数据端口。服务端与客户端分别使用自己的类型编号，不能混用。
先排除不可能的候选，再按存在类型依赖的连通组搜索一致解，综合各节点的目录类型偏好。
已固定类型的连接不把互相独立的泛型选择合并；所有同等偏好的解均保留，不根据节点顺序选择其中一个。
搜索、候选扫描和域复制共享 200 万工作量上限，超限时明确提示，可通过指定类型减少分支。
未使用的泛型可以保持未选定；参与连接或常量的类型仍有歧义时必须明确。

例如整数加法节点：

```json
{
  "id": "sum",
  "type": "math.add",
  "position": {"x": 10, "y": 20},
  "data": {
    "giaTypes": {"a": "Int"},
    "overrides": {"a": 1, "b": 2}
  }
}
```

列表使用 JSON 数组。字典使用键值对数组，例如 `[["old",3],["new",4]]`，重复编码键会拒绝。
枚举支持编号或参考库内唯一匹配的名称／翻译；无法匹配的文本不推断为序号。
局部变量句柄与结构值不能作为普通常量；客户端字典、未收录类型及结构 ID 绑定尚未支持。

端口数量与参考协议一致时按方向分别编号；不一致时只自动采用唯一的类型匹配。
需要人工核对时使用 `data.giaPortMap`，例如 `{"inputName":0,"otherInput":1}`。
编号从 0 开始，数据输入和数据输出分别计数；只接受已有数据端口、非负整数及模板范围内的编号。
多个同方向端口不能占用同一编号。显式映射不代表客户端兼容性已经核验，应按真实导出或参考定义填写。

多路分支 `flow.branch.multi` 的 `controlExpr` 固定使用输入 0，输入 1 保存分支标签。
`data.branchFlowOutLabels` 最多 10 个字符串；`branch1`、`branch2` 等流程输出接在默认分支之后。
整数分支的标签必须可精确解析为 int32；字符串分支保留标签文本。
`sequenceFlowOutCount`、非空 `controls`、执行间隔和未识别语义属性会提示尚未映射。

节点 label 转为附着注释；文档注释保存文本与坐标。
一个节点已有注释时，额外附着注释保存为图注释，缺少坐标时使用原节点位置。
画布 ID、注释折叠与固定状态等界面信息保存在原始 JSON 归档中，不作为游戏字段写入。

## GUID 与归档

服务端图从参考命名空间 `0x40000000`、客户端图从 `0x40800000` 分配，各检查 `0x999A` 个候选编号。
起点由画布 SHA-256 确定；扫描全部已归档主资产 GUID，包含大型资产预览之外的条目与结构 JSON。
遇到占用向后查找，已有相同生成文件重新核对完整摘要后去重；归档损坏时拒绝自动分配。
文件名包含画布来源摘要的前 12 位，完整 SHA-256 仍用于内容身份检查。

这些保证适用于单个服务实例及已导入归档。外部文件与跨进程写入不在分配保证内；
已有文件的已知 GUID 复制与关联引用处理见 [GUID 复制](MILIASTRA_GUID_2026-10-08.md)。
转换入口沿用 `POST /gm/api/miliastra/{SHA-256}/convert`，新结果 201、已有结果 200、映射问题 400。
画布归档类型为 `GRAPH_JSON`，生成文件为 `GIA`，随后可继续转为 `GIA_JSON`。
