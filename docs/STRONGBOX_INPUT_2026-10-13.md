# 还圣奥迹材料与请求校验

对照固定 AstaPS `7cc148d1f752a43d4b9146b3b73f26875902546f` 与 HunkyMeow 的兑换入口，
发现参考实现与本项目都只检查 GUID 是否存在。重复 GUID、低星材料、锁定或穿戴装备可能被消耗。
本批先修复正式兑换入口的整批材料检查。

## 行为

- 要求正兑换次数、互不重复的材料 GUID、数量准确，以及当前玩家拥有的独立五星圣遗物。
- 拒绝锁定、穿戴、数量异常、过期定义、其他物品类型和未知 GUID；删除前校验整个材料列表。
- 删除前检查所有可能产物均为有效五星圣遗物；空或损坏目录返回参数错误。
- 使用当前库存锁串行执行，阻止合成与兑换回调重入；容量计算包含材料释放的格子。
- null、畸形协议和无效数量返回 `RET_RELIQUARY_DECOMPOSE_PARAM_ERROR`。

资源的 40 组定义当前均为每件产物消耗 3 件、材料五星、最多 39 件产物。
本批采用这组已核对约束；[完整资源目录](STRONGBOX_CATALOG_2026-10-13.md)随后已接入资源规则加载。
