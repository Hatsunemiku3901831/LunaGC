# 未归的熄星：剧情任务接取与即时解锁

## 当前实现

使用提供的资源中的原始任务，接取仍走现有任务系统与 `QuestListUpdateNotify`。

| 入口 | 原始条件 |
| --- | --- |
| 第一章 4111101 | 活动条件 2001001：第 1–14 天，冒险等阶至少 20 |
| 第二章 4111200 | 4111114 完成，且满足第 3–14 天的条件 2001002 |
| 第三章 4111301 | 4111213 完成，且满足第 8–14 天的条件 2001003 |
| 第三章支线 4112601、4112701、4113115 | 4111309 完成，且满足第 8–14 天的条件 2001303 |
| 菲谢尔剧情条件 1200130 | 原任务 4111309 的完成事件；中型与大型领奖条件独立计算 |

登录在安装当前活动管理器后触发接取条件；GM 刷新活动与每日阶段解锁也触发。
剧情状态变化时，只重新触发资源中依赖该任务的活动条件，并使用已有活动通知同步。
关闭的活动、未安装的管理器、缺少世界，以及关闭任务或大世界脚本的配置不会启动活动任务。

任务接受条件中的 `LOGIC_NONE` 按全部满足处理。这里仅调整接取判定，
没有更改任务完成／失败条件及其他系统对 `LogicType` 的使用。
接取时重新读取任务状态和活动条件，避免沿用已经过期或已经变化的肯定结果；
依赖事件参数的交付物品条件保留原事件结果，显式 AND／OR／NOT 保留其含义。
重复通知不重启已接或已完成的任务。
