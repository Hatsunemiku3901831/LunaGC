# 怪物离场前死亡事件

## 已接入

`Scene.killEntity` 在取得唯一死亡处理权后、移除实际怪物之前，同步执行
`EVENT_MONSTER_DIE_BEFORE_LEAVE_SCENE`（55）。回调期间 Lua 可以查询仍在场景中的
同一怪物；原有移除、死亡结算、任务和掉落流程随后继续。

事件字段按固定原服务端 `Monster::onDie` 核对：

| 字段 | 内容 |
| --- | --- |
| `source_entity_id` / `evt.source_eid` | 死亡怪物实际实体 ID |
| `param1` | 怪物配置 ID |
| `param2` | 原始击杀者 UID；客户端召唤物追溯所属角色，无击杀者时为 0 |
| `param3` | HP 变化原因；伤害入口沿用 HP 原因通知中的值，未提供原因时为 0 |
| `param4` | 怪物类型 |

## 执行与生命周期

- 在死亡线程、场景锁内执行，避免等待持有同一场景锁的后台 Lua 回调。
- 复用跨组调用的上下文保存与恢复，保留外层场景、组、实体和事件参数；
  支持 Lua 内嵌套击杀、脚本异常和已有场景锁。
- 只接受实际实体、加载的原始组对象和当前触发器；在条件返回后再次检查有效性。
- 场景玩法怪物出生时绑定实际轮次。倒计时、已结束／超时、组替换、场景销毁和
  同一组开启的下一轮均不能接收旧怪物计分。
- 同步回调期间保留轮次占用；回调停止战斗后也不能在返回前替换为新一轮。
- 重复、并发和重入击杀仅执行一次死亡事件与结算。
