# 宝箱开启与调查手册进度

参考 AstaPS 固定提交 `7cc148d1f752a43d4b9146b3b73f26875902546f` 的普通宝箱手册事件入口，
在本项目实际脚本掉落和旧掉落路径接入 TRIGGER_OPEN_CHEST_WITH_GADGET_ID。

## 修复

- 脚本掉落的 drop ID／标签、成功的旧掉落或回退路径，均在实际成功开启后以宝箱 gadget ID 推进玩家手册目标。
- 同一普通宝箱的交互串行处理，拒绝同时／重复／回调重入的开启；还原出的 ChestOpened 状态同样不可再次发奖或计数。
- 普通宝箱只有所在世界的主人可以打开。旧掉落路径现在采用同一规则。
- 插件取消旧路径开启时返回失败，不发奖、不消耗宝箱、不推进手册；取消解除后可以重新开启。
- 失败或抛异常的交互会释放处理中标记，允许正常重试；进度不超过目标资源声明的总数。
- 首领宝箱保留逐玩家领取语义，不作为普通宝箱推进手册。
- 首领脚本缺少 drop_tag 时不会误入普通宝箱掉落分支，转向已有首领回退处理。
- 只更新匹配且开放的宝箱任务，不重新计算其他类型的目标。
