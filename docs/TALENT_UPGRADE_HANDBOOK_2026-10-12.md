# 天赋升级与调查手册

本批补齐升级入口缺少的 `TRIGGER_UPGRADE_TALENT`。
实际资源目标 60053 属于章节 10007，要求成功升级天赋 3 次；事件参数携带技能 ID。
直接 GM 设置等级不增加这一计数，关闭手册不妨碍正常升级。

## 修复

- 只升级当前角色技能库内已经学习的技能，拒绝其他角色技能及异常当前等级。
- 在扣料前检查下一等级是否有效、技能组和等级资源是否匹配、突破条件是否满足。
- 技能组 ID 运算使用长整数，避免溢出产生错误资源 ID。
- 在玩家库存锁内完成检查、支付与升级；拒绝支付回调重入，并保证清理执行标记。
- 仅在实际升级成功后推进手册，保留技能数值刷新和现有技能升级通知。
