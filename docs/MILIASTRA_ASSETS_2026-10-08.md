# 千星资产归档与格式校验

## 使用

GM 中打开「千星资产」，选择 GIA／GIL／GIP／GIR 或节点图 JSON 后点击「导入文件」。
支持批量选择、按名称／文件名／SHA-256 检索、按文件类型筛选，每页 20 条。
「导出原文件」返回导入时的完整字节，保留未知 protobuf 字段、JSON 扩展属性与文件排版。
本页的操作无需玩家 UID，沿用 GM 的令牌与回环地址限制。

资产写入用户数据目录下的 `miliastra/assets/`，目录根由 `folderStructure.data` 决定。
按完整文件的 SHA-256 去重；GUID 相同但内容不同的版本可分别归档，会提示存档合并时的 ID 冲突。
原文件与元数据先写入临时目录，再以原子重命名发布。导出前核对长度与 SHA-256，损坏文件不会作为成功结果返回。
二进制、节点结构 `.gia.json` 与镜头 `.camera.json` 最多 32 MiB、编辑器画布 JSON 最多 8 MiB、归档元数据最多 4 MiB，最多 2000 个归档及 512 MiB 原文件总量。
文件名仅作展示与下载名称，上传不接受目录路径。存档损坏条目在列表中计数提示。

## 格式和校验

四类容器均按大端序读取：声明长度、版本、`0x326` 标记、文件类型、负载长度，以及尾部 `0x679`。
合法空容器为 24 字节。扩展名须匹配类型；未知容器版本可归档，但会显示尚未核验提示。
protobuf 检查根字段、已知资产元数据与组的边界；组嵌套最多 64 层，字段和资产数量均有上限。
GIA 显示资产名称、GUID、分类、类型及关联标记；GIL 显示已知的关卡名称。
GIA 最多 100000 项资产，所有主资产 ID 均会检查；只存储前 100 项预览元数据，避免大型像素画撑大列表。
未知内容字段保持不透明；GIP／GIR 目前不声称具备完整内容解释器。

编辑器画布 JSON 支持 schemaVersion 1／2 和上游服务器／客户端环境：
严格 UTF-8 与 JSON，拒绝重复属性、超限嵌套、非有限数值、重复节点／连接 ID、重复连接、失效的节点引用和注释。
目录的端口方向、数据类型、环境与未知节点仅产生预览提示，不因未经核验的截图推断拒绝新节点。
归档不会执行节点、导入实体或自动修改游戏场景。

节点 GIA 可转换为 proto 字段对应的 `.gia.json`，编辑后重新导入并转回 GIA；
常量、客户端字段和各层未知字段保留，完整规则见 [节点结构转换](MILIASTRA_NODES_2026-10-08.md)。
此格式使用 `GIA_JSON` 类型；画布格式使用 `GRAPH_JSON`，已支持带诊断的 [画布 JSON 转 GIA](MILIASTRA_CANVAS_2026-10-08.md)。
画布的流程／数据连接、常量、泛型、分支与注释按已核对参考映射编译，剩余歧义会显示原因。
普通节点 GIA 与结构 JSON 还可 [反向生成编辑器画布](MILIASTRA_REVERSE_2026-10-08.md)，
保留原始来源，未编辑时还原原字节，编辑后沿用原 GUID 与已有节点索引。
GIA 与节点结构 JSON 可复制并重新编号，联动更新实体、镜头、普通节点图及已知 GUID 引用；
原文件继续保留。自动避让、指定起点、去重与未解析引用的边界见 [GUID 复制](MILIASTRA_GUID_2026-10-08.md)。

## 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/gm/api/miliastra?q=&type=&offset=0&limit=20` | 列表；limit 上限 100 |
| POST | `/gm/api/miliastra?name=文件名` | 原始请求体上传，建议 application/octet-stream |
| GET | `/gm/api/miliastra/{SHA-256}/download` | 原文件下载 |
| POST | `/gm/api/miliastra/{SHA-256}/convert` | 节点 GIA 与结构 `.gia.json` 双向转换，画布及镜头 `.camera.json` 转 GIA |
| POST | `/gm/api/miliastra/{SHA-256}/canvas` | 普通节点 GIA／结构 JSON 转为带原始来源的编辑器画布 |
| POST | `/gm/api/miliastra/{SHA-256}/camera` | 从 GIA 提取带原始来源的镜头 `.camera.json` |
| GET | `/gm/api/miliastra/camera-templates` | 五种镜头模板与来源信息 |
| POST | `/gm/api/miliastra/generate/camera?name=镜头.gia&firstGuid=...` | 镜头 JSON／批量变体生成与归档 |
| POST | `/gm/api/miliastra/generate/voxel?name=体素.gia&unit=0.01&alphaThreshold=128&x=0&y=0&z=0&firstGuid=...` | 体素数组转 GIA 并归档 |

首次导入返回 201，内容重复返回 200；参数／格式问题为 400，未授权 403，超限上传 413，不存在 404。
大文件直接受限读取请求流，其他 GM JSON 接口的请求体限制保持原配置。
