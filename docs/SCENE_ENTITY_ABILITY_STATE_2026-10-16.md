# 场景实体出场时的能力参数同步

## 修复

怪物、服务端机关、客户端机关、掉落物、载具和 NPC 的 `EntityAuthorityInfo`
此前始终发送空能力块。重新可见或向其他玩家发送实体时，已记录的能力覆盖参数与
当前 SGV 因而无法从这条出场路径发送。怪物携带的武器也使用空能力块。

这些路径现已使用实体自己的 `AbilityRootState.toSyncState()`：

- 发送已安装根能力的运行覆盖参数，以及有参数的未知根原始描述、override 和未知字段。
- 发送当前有限的 `SGV_` 值，包含零值；没有根能力时也能发送已有 SGV。
- 每次序列化读取当前值，已构造的包保持不可变；沿用根参数冲突过滤和实体生命周期检查。
- 怪物本体和武器分别使用各自的实体状态，武器缺失时保留空块。
- 单体、批量出场和重新可见通知都通过实际实体序列化得到这些数据。

此处沿用未初始化客户端的具名参数覆盖路径，`is_inited` 保持 false。
资源默认根没有覆盖参数时仍由客户端初始化；不把这份部分状态称为完整根列表或完整恢复包。
