# 当前资源的持续燃素回调

## 客户端依据

经 SHA-256 校验的客户端：配置类型 31489、运行类型 83763。
`0x151fa0d50` 发送调用号 **135**，随后读取配置的速度与周期并相乘。
默认周期的构造方法 `0x14d498550` 使用四个正向字节置换表；`0x152125890` 用逆向表还原。
置换前输入为 `0x3e99999a`，对应 **0.3 秒**，不依赖运行时 XOR 密钥。
模式 28080 为 Cost=0、Add=1、Set=2；目标 54373 为 Auto=0、Self=1、Team=2、Vehicle=3。
自动目标在自身燃素耗尽时选用父级队伍池；明确 Vehicle 不回退。
调用的消息工厂与其他无参数通知共用。本次只接受空载荷，没有发明“客户端上报扣除量”字段。

## 接入

- 接入资源 `ChangePhlogistonMixin`，每条调用消耗／补充一次 **speed × interval**；不再额外开服务端周期定时器。
- canonical speed/interval/costType 优先，保留原始速度、三种周期导出名称及原始模式。缺省周期使用上述原生值。
- 当前 43 个资源节点包含 Cost 与一个 Add 节点，均可走该入口；Set 的计时语义尚无当前资源／原生调用配对，拒绝猜测执行。
- 确认调用号与 mixin 一致，并核对当前承载实体、玩家、父控制器、开关和条件。移除父实例后不能回退根能力继续扣除。
- 明确 Team、Self、Vehicle 与 Auto 目标选择各自执行；明确车辆池为空不改扣队伍池，Auto 可回退队伍。
- 空消息以外、坏表达式、非正周期、负速度和未知目标／模式不产生额外消耗。
- 耗尽后的动画和提示数组仍由客户端监听其燃素变化；本次没有额外重发这些视觉动作。
