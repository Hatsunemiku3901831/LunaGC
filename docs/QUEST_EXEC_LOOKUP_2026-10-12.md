# 任务动作编号与名称映射：2026-10-12

参考 AstaPS 的[任务动作索引修复](https://github.com/MeChen618/AstaPS/commit/31709f47a53f9bdb8fc994bb39934aba1043fbf0)。
本地 `QuestExec` 用 `QUEST_CONTENT_` 前缀过滤动作枚举，导致公共编号／名称索引为空，
所有查询均返回 `QUEST_EXEC_NONE`。修正为 `QUEST_EXEC_`，保留既有 API 名称和未知输入回退。

十项基线中，两项遍历全部声明动作的检查失败，八项未知输入对照通过。
修复后的专项覆盖 **71 个动作**的编号和名称、编号唯一性、NONE／UNKNOWN 常量，
以及无效编号、null、空名称和其他任务域名称的回退。

当前项目主 Java 源码未找到该公共查询接口的调用方；标准任务资源的 Gson 枚举解析独立于这个索引。
因此，本批修复公共接口契约，没有将它描述成现有任务资源解析或所有任务玩法已经修复。
最终 **141 项／8 套件**关联回归与打包通过，失败、错误、跳过均为 0，耗时 1 分 56 秒。
