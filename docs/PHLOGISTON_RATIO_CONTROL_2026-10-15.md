# 燃素倍率控制

## 接入与计算

- 普通动作及周期 mixin 保留原始 `JDIMELLBMFO` 开关；可读配置名 `useRatio` 优先，明确 false 不被原始 true 覆盖。
- 当前周期 Cost 的扣除量为 `speed × interval × 当前所选燃素存量`，每次读取更新后的值。关闭倍率时仍按绝对点数执行。
- 补充和普通动作设值的倍率按池容量计算：队伍 100、龙 50；倍率 1 的 Add 可从空池补满，不再只补 1 点。Cost／Sub 倍率使用当前存量。
- 倍率计算与燃素写入在同一锁内执行，保留零值、上限及无限燃素控制。负倍率不反向产生奖励，无效表达式不执行。
- 周期 mixin 兼容原始目标 `BBIPIGDBGFJ`，可读 `targetType` 优先。Team、Vehicle、Self、Auto 使用各自所选池；空 Vehicle 不转扣队伍，Auto 可回退。
- Auto 遇到车辆存量为 NaN／无穷数会拒绝，不能把坏状态当作空池后转扣队伍；明确 Team 不读取无关车辆存量。
- 原来的旧 ratio/determineType 配置继续按绝对数值处理；这里的 `useRatio` 是百分比模式，和动态表达式操作数 `ratio` 分开。

## 依据及边界

当前经 SHA-256 校验的配置 31489 在 `+0x50` 持有倍率开关、`+0x54` 持有目标；
`0x151fa0d50` 将两者传入 `0x151a1a9a0`。
该方法在开关为 true 时读取所选池 `+0x20` 乘以扣除量；
池类型 84642 的 `0x14aa4ec20` 读取同一当前值，`0x14b4da140` 则将它除以 `+0x18` 的上限。
因此周期 Cost 使用当前存量，不应误写成消耗效率或上限倍率。

动作配置 87220 的倍率开关为 `+0x6c`。当前资源有 20 处原始开关，均为 Add=1，
包括活动 InfinitePhlogiston 初始化和场景补满燃素。
这些补充配置使用容量基准，是从资源用途得出的兼容实现；其动作原生入口 `0x147b469f0` 只转交 ILFix，
本次没有宣称已解出客户端热修复中的全部 Add／Set 计算分支。
普通 Set 的容量倍率及周期 Add 倍率已提供服务端语义；当前资源没有开启该开关的对应实机样本。

## 普通动作的显式池目标

当前资源有 225 个普通 `ChangePhlogiston` 动作，其中 **94 个指定 Team、2 个指定 Vehicle**。
之前普通动作没有保留 `targetType`，即使显式指定队伍也仍按能力拥有者选择燃素池。
现在普通 Cost／Sub／Add／Set 与周期变化共用显式选池入口：

- Team 的倍率扣除读取队伍存量，倍率 Add／Set 使用队伍容量；能力属于龙时也不改变龙池。
- Vehicle 读取自己的承载车辆；缺少车辆不会转扣队伍，空龙池的显式 Vehicle Add 正常补充。
- 明确 Team 不读取无关龙池的 NaN；缺少所选队伍池或未知目标返回失败。
- 未指定池目标的动作保留原先能力拥有者选池；`target` 仍表示动作承载实体，不与 `targetType` 混用。

这是对现有资源控制字段的兼容接入。普通 Add／Set 的完整客户端 ILFix 分支仍未解出，

## 旧版扣除入口的倍率与选池

`PhlogistonCostMixin` 之前只读取 `speed`，忽略已经解析的倍率和目标字段。
现在旧入口复用相同的燃素写入逻辑：

- `useRatio`／`JDIMELLBMFO` 开启时，按每次执行时所选池的当前存量扣除；明确 false 优先。
- `targetType`／`BBIPIGDBGFJ` 可指定 Team、Self、Vehicle 或 Auto，可读目标优先。
- 未指定目标时保留旧入口的拥有者池规则，空龙池不自动转扣队伍；明确 Auto 才允许回退。
- 缺少明确车辆、未知目标及无效池返回失败，队伍目标不读取无关的坏龙池。

这是旧配置入口的服务端兼容补齐，没有把它当作当前客户端新增原生类型的证明。

## 数值枚举形式的模式与选池控制

当前配置字段使用字符串接收可读名称；Gson 读取数值形式的枚举时会产生 `"0"`、`"1"` 等字符串，
原来执行器将其当成未知模式或目标拒绝。现在统一解析相同的名称和整数编号：

| 控制 | 名称与编号 |
| --- | --- |
| 普通动作／周期模式 | Cost=0、Add=1、Set=2 |
| 燃素池 | Auto=0、Self=1、Team=2、Vehicle=3 |

再次按 SHA-256 校验三个客户端输入，从元数据默认常量表直接读取类型 21250、28080、54373，
确认上述全部编号。没有只按字段声明顺序推测编号。
普通动作、周期回调和旧版扣除入口共用选池解析；模式仍按原先的存量／容量倍率计算。
可读字段优先于原始字段，明确关闭倍率仍有效，未知编号及小数不会回退或修改燃素。
普通动作原有 Sub 别名继续有效；当前周期 mixin 不接受这个旧别名，Set 周期模式仍拒绝执行。
