# 分离服务的 JSON 字面值保留

## 复现与修复

继续核对固定参考库与远端账号传递路径时，发现 `IDispatcher.decode` 会手工移除引号和反斜杠。
消息包含路径、转义引号、控制字符或嵌套 BSON 文本时，会损坏字段内容或解析失败。

现在逐层使用 JSON 解析器展开消息字符串，最多兼容三层外部字符串包装。
对象字段中的字符串保持原值，不再进行全局替换；直接对象、数组和空值保留相应语义。
超过支持层数或结构不完整的消息会失败，不能把损坏数据当成成功结果。

这也使 BSON Extended JSON 文本能够原样传递，保留保存版本所需的 int64 类型和精度。
本次只完成传输前提，远端账号副本的可写绑定与条件保存仍需接入。
