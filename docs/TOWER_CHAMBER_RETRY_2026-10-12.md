## 接入

- 深渊副本重试验证楼层、当前间、选队、所属角色、技能库、能量上限和已保存的起始快照。
- 传送预设上半队伍与首个角色；失败且尚未离开原场景时恢复旧队伍索引。
- World 在传送事件后与新场景准备后再次检查资格，通过才发布替换场景。
- 成功后恢复上下半角色的血量、生命之契及普通／特殊能量；保留当前间数、返程位置和深渊结算观察者。
- 重置两队普通技能的多次充能队列，并向下半队伍同步完整充能状态。
- 仅清除所属角色技能关联的共享冷却，保留未选角色和无关共享组。
- 清除旧挑战的 TowerManager 计时／进行标志，重新发送当前间、星级与技能禁用通知，由 Lua 开始新的挑战。
- 缺少有效快照的旧深渊上下文拒绝重建；单独的深渊布尔标记不能替代选队和当前间验证。

现有 void 重试 API 与普通副本资格路径保留。
这是角色状态恢复与入场资格的适配，Lua 阶段和组状态、半间动画与完整客户端流程仍需继续验证和适配。
