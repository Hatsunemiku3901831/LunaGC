# 摆设制作完成后的天赋材料返还

## 完成的流程

单条及批量领取现在会发放[已冻结的天赋返还计划](FURNITURE_TALENT_PLAN_2026-10-13.md)。
领取不重新计算角色天赋或当前配方；没有返还计划的旧任务仍按既有流程领取家具。

- 在支付加速瓶、发放家具前，核对每项返还材料的真实定义、所有者、数量上限和材料背包容量。
- 单条预检考虑本次消耗最后一瓶加速瓶释放的槽位。批量预检按领取顺序模拟瓶子支付和材料新增，检查整批的峰值容量及累计数量。
- 批量父记录保存每项返还计划的独立副本，后续修改任务或资源不改变已预约数量。
- 发放家具前保存包含全部返还材料、预期数量及发放前数量的领取记录。
- 每种材料检查实际库存增量、同步保存拥有者物品，再记录物品持久化 ID 与已确认状态。
- 全部返还确认后才推进首次制作信任经验、纪行任务进度及源槽移除。
- 单条和批量成功回包使用已确认的产物列表，包含家具和返还材料；批量聚合相同材料，仅发一个批量响应。
- 拒绝发放、伪成功、部分发放、重入或保存中断时保留待确认记录，拦截再次领取。

本批沿用已核对的主要奖励列表字段。次要提示列表的原生语义仍不明确，尚未据此填入返还值。
物品与家园保存不是同一数据库事务；异常可能已发放部分家具或材料，当前保留记录等待核对，尚未自动补偿或自动重放。
