LunaGC 7.1 本地运行

项目：C:\GS
游戏：C:\GAME\Genshi
来源：https://github.com/invoker-bot/LunaGC

常用中文入口：启动游戏.cmd、启动服务.cmd、停止服务.cmd、查看状态.cmd、管理后台.cmd。
恢复原版客户端.cmd 可在游戏退出后还原客户端。

双击 Play-GS.cmd：启动本地服务，安装客户端补丁，再打开游戏。
双击 Start-GS.cmd：只启动本地服务。
双击 Stop-GS.cmd：保存玩家数据并停止服务；数据库保留运行。
双击 GS-Status.cmd：查看服务、数据库和客户端补丁状态。
双击 Open-GM.cmd：打开已授权的 GM 管理页面。
双击 Restore-Client.cmd：游戏退出后恢复原版客户端 DLL。
双击 Rebuild-GS.cmd：服务停止时，从当前源码重新构建服务端。
双击 Rebuild-Patch.cmd：从当前补丁源码重新编译客户端补丁，下次启动游戏时安装。

本地账号：local
密码：任意非空密码（仅本机测试配置）
首次进入游戏时创建角色；角色 UID 预留为 10001。

服务地址：http://127.0.0.1:8088
游戏端口：127.0.0.1:22101 UDP
数据库：127.0.0.1:27017
日志：C:\GS\local\logs 与 C:\GS\logs
玩家数据：C:\GS\mongodata；不要删除此目录。
公告、卡池和商城等运行数据：C:\GS\local\data；备份时一并保留。
配置：C:\GS\.env 和 C:\GS\config.json。

Java 17、MongoDB 和编译工具保存在 local 内，不依赖系统 PATH。
本机使用 Windows 便携运行方式，原项目 Docker Compose 配置仍可另行使用。
Docker、WSL 和虚拟化功能暂不部署，以后仅在用户明确要求时操作。
命令行可使用 .\task.cmd serve 从当前源码更新便携服务；不会启动 Docker。
正常关闭启动窗口不会关闭已启动的服务器与数据库。
重启电脑后需再次运行 Start-GS.cmd 或 Play-GS.cmd。

客户端原始 DLL 备份：
C:\GAME\Genshi\YuanShen_Data\Plugins\Astrolabe.dll.lunagc-bak
C:\GAME\Genshi\YuanShen_Data\Plugins\AccountPlatNative.dll.lunagc-bak
切回官方服务器前，请退出游戏并运行 Restore-Client.cmd。
游戏版本更新后需要重新确认服务端、资源和补丁是否兼容。

LunaGC 7.1 为社区开发项目；服务健康不代表所有任务、活动或玩法均已完整实现。
